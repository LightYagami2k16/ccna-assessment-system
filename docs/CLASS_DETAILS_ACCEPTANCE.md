# Your classes detail popups

Class cards display only the class name and Show details. The popup contains the class identifier, active status, term, administrator teacher information, roster and password reset controls, join code/QR/manual enrollment, individual deletion selection and edit/delete actions. Search and bulk tools remain on the library page. Search filters class cards and, inside their popups, only the matching enrolled students. Clear search restores the roster expansion state and clears selections as before.

The popup closes before editing and when leaving Your classes or filtering/removing the selected record. Existing class form drafts remain mounted. Closing the popup retains controlled roster expansion and selection state. Nested join-code confirmations do not cancel the parent popup; shared focus handling only handles the currently owning dialog. The shared popup has a configurable Class details label.
