# Redesign Phase 4 — Instructor Visual QA

Use the instructor account and check each screen at approximately 1440 px,
1024 px, 768 px, and 390 px wide.

## Shared workspace

- The active page title and description remain readable.
- The navigation position badge does not overlap the title.
- Direct header buttons stay content-sized on desktop.
- Header buttons stack to full width below 800 px.
- Collapsible controls retain visible focus and do not overflow.
- Confirmation dialogs keep both actions visible and trap keyboard focus.

## Question Bank

- Course Modules, Create Question, and Question Bank have consistent spacing.
- Course groups collapse without changing neighboring group widths.
- The question table scrolls horizontally and retains every column.
- Bulk action buttons stack cleanly on narrow screens.

## Quiz Builder

- Create Quiz stays aligned with the Quiz Builder heading.
- Course groups and quiz cards retain readable titles and status badges.
- Quiz settings change from multi-column to one column below 800 px.
- Question-selection controls do not overflow.

## CLI Practicals

- CLI practical builder heading is not compressed by its action button.
- Criterion forms change from three columns to one column below 800 px.
- Practical course groups and cards remain full width.
- Answer-key command blocks scroll without widening the page.

## Classes & Assignments

- Create Class controls stack correctly.
- Class cards, enrollment tools, QR codes, and bulk actions remain contained.
- Assign Quizzes course groups collapse without horizontal overflow.
- Pending-request empty state has consistent inset spacing.

## Exam Controls

- Assignment schedules remain grouped by course and class.
- Accommodation fields reflow to one column on small screens.
- Accommodation tables are keyboard-focusable and horizontally scrollable.
- Live-monitoring class and student summaries do not overlap event counts.

## Student Results

- Export controls move below the heading at medium widths.
- Class, student, and quiz groups remain independently collapsible.
- Quiz and CLI result tables retain score, events, time, and action columns.
- Reset confirmation explains what will be permanently removed.
