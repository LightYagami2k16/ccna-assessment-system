Diagnosis: every operation disables the input, awaits Edge response and then a second full snapshot before returning. Console clears its draft after that await, which would erase text typed during the wait. Timer ticks also rerender/filter/join full command history repeatedly. Existing refresh coordination has no way to adopt mutation responses or prevent older in-flight snapshots from overwriting them.

Design: consume canonical command responses immediately with guarded snapshot adoption. Add a bounded20-operation serial type-ahead queue for full-builder duels; one request at a time, next sequence/revision only after verified acknowledgement. Clear submitted draft immediately, preserve subsequent typing. Echo only the currently dispatched command with its authoritative pre-command prompt; queued commands show a pending count, never invented results or locally awarded score/HP. Unknown transport freezes exact request for explicit retry. Definitive failure/paused/offline/expired/ended state discards unsent operations into a copyable list, not automatic replay after resume. Server remains authoritative. Memoize console/history and keep focus independent of ACK/timer ticks.

Left fill anchors left and shrinks left; right anchors right and shrinks right. Keep character art mirrored and reduced motion.
